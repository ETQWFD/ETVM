常见问题

微信打开官网显示“无法访问”？

官网部署在 GitHub Pages，提供 HTTPS（*.github.io），微信内置浏览器通常可直接打开。若出现提示，请复制链接到系统浏览器打开一次，或点击右上角“在浏览器打开”。本页所有资源均为 https 直链，无被微信拦截的域名。

为什么不用网页 / WebView 实现？

v3.0.0 起虚拟机界面全部改为 Java 原生实现，不依赖网页内核。原生界面更流畅、权限申请更可靠、文件系统访问不受 WebView 限制，ROM 商店刷新等历史问题一并根治。

ROM 商店下载怎么没有进度？

v3.2.0 已重构：下载全程显示实时进度（进度条 + 百分比 + 已下载/总大小 + 速度，约 0.7 秒刷新），下载失败也会明确提示 HTTP 状态码，不再黑盒等待。电脑版同步支持。

商店里怎么没有 Android 10~16？

官方 android-x86 项目只到 Android 9.0；Android 10+ 为社区 x86_64 发行版（体积 >1GB，超出精简镜像约束）。商店已为 10~16 全部建卡并标注“镜像整理中”，4~9 官方镜像与两款内置系统可直接使用。

内置安卓4.4怎么用？

创建虚拟机时在【系统来源】选择“内置安卓4.4”（或“内置安卓7.0”），无需上传、无需下载、无需等待安装，创建完成后直接启动进入系统，且该虚拟机不可删除。

权限申请为什么在 Android 13+ 弹不出来？

本版本针对 Android 13/14 做了媒体与通知权限兼容（READ_MEDIA_* / POST_NOTIFICATIONS），创建向导内可逐项申请并实时显示授权状态；悬浮窗权限需在系统设置中手动开启（App 会一键跳转）。

手机版之前“运行不了/进入首页卡死”修好了吗？

v3.1.0 已修复：① 内置镜像改为后台解包，不再阻塞首屏；② 界面缓存，重复进入秒开；③ 全局崩溃兜底——任何异常不再闪退，写入 crash.log 并自动回到首页。若仍有问题，把 crash.log 发给我们即可。

电脑版怎么用？

下载 Windows 版压缩包，解压后双击 ETVM.exe 即可（内置 Java 运行环境，无需安装）。与手机版功能一致：内置 ET-OS 7.0、ROM 商店、连接储存、三语言、主题、检查更新。

怎么切换语言和主题？

首页点开任意虚拟机 → 设置，顶部即可切换 中文/English/日本語 与 5 套主题，实时生效。

检查更新是怎么工作的？

自动/手动检测 GitHub 最新 Release：发现新版本会询问是否下载，选择是即在软件内下载，安卓版申请“安装未知来源”权限后直接安装，电脑版下载便携包到下载目录。

为什么只支持安卓 ROM，不支持 Windows？

按设计约束：本虚拟机面向安卓生态，只支持安卓系统镜像（32 位 / 64 位）。上传 Windows 镜像会被检测引擎识别并明确拒绝。

ROM 商店列表刷新失败怎么办？

v3.0.0 已修复：商店列表改为 Java 原生读取 assets 目录并做实时源检查，不再经过 WebView 的 fetch(file://) 拦截链路。点“刷新列表”即可。
